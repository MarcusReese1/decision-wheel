# decision-wheel
A colorful wheel that randomly selects between user choices.

## Current features

- Responsive decision-wheel interface
- Add and remove custom choices
- Automatically redraw colored wheel sections
- Input validation for empty and duplicate choices

## Teammate tasks

- Implement the wheel spinning animation
- Randomly select and display the winner
- Add optional sound or celebration effects

Open `index.html` in a browser to run the project. No installation is required.
